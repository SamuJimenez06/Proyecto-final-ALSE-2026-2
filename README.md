# Gestor de Domótica para hogares - Proyecto Final ALSE

Proyecto final desarrollado en C++, Qt5, SQLite y QtCharts para la gestión automatizada de dispositivos del hogar.

## Estructura
- `include/`: Cabeceras (.h) con POO, polimorfismo y base de datos.
- `src/`: Implementaciones (.cpp), interfaz gráfica y `main`.

## Compilación y Ejecución
```bash
mkdir build && cd build
cmake ..
make
./ProyectoFinal
